# 벙커 쉘터 방치형 — 기획서 및 실행 계획 (구글 플레이 출시용)

## 0. 배경

지금 게임은 스테이지 60대까지는 괜찮게 오르지만, 그 뒤로는 계산된 성장도, 살 것도, 모을 것도 없습니다. 조사로 확인한 원인입니다.

| 문제 | 원인 (코드 위치) |
|---|---|
| 60 이후 정체 | 좀비 체력은 스테이지마다 +12%, 수입은 +9%. 연사·탄창은 40~50, 벙커·울타리는 60~65에서 최대 (`src/config.js:52-56`, `src/buildings.js`) |
| 스테이지 조작 없음 | 처치 +1, 뚫림 −2로만 바뀜 (`src/zombies.js:213,226`) |
| 동료 성장 없음 | 모두 같은 총 능력치, 개인 스탯 없음 (`src/crew.js:118-123`) |
| 무기 | 공격력 레벨에 묶여 모양이 바뀜 (`weaponLookName`, `gunLook`) |
| 크기 불일치 | 지하만 한 단계 더 확대 → 사람이 지상 30px, 지하 40px (`hud.js` fitStage) |
| 그림자 | 2D로 밀어 그려 물체를 뚫음 (`sprites.js` castSpriteShadows). 지하는 높이 0으로 투영해 어긋남 (`engine.js` castShadow) |
| 반짝임 | 색 비교라 그림자·조명까지 빛남 (`layers.js` flashDiff) |
| 도트 | 좀비는 타원 덩어리에 띠 명암(`tools/zombiesB.py` render_volume)이라 도형 티가 남. 아이콘 16px를 소수 배율로 늘려 흐림. 초상화는 게임 도트를 잘라 씀. 옆모습에서 반대편 다리·고관절이 보임 |
| 연출 | 총구 불꽃이 총구와 어긋나고 잔상이 남음. 총알 방향이 총구 방향과 다름 |
| 사운드 | 백색소음 필터 13종, 음악 없음 (`src/sound.js`) |
| 화면 | 정수 배율과 섬 크기 상한 때문에 PC에서는 섬이 작고, 폰에서는 UI가 높이의 40%를 가림 (index.html 168-182) |

목표는 구글 플레이에 내는 상업용 방치형 쉘터 게임입니다. 이 문서로 기획을 확정한 뒤 단계별로 만듭니다: 경제·과금 균형, 콘텐츠, 화면, 아트·연출, 사운드, 기술, 출시.

## 1. 정해진 것 (답변 반영)

| 항목 | 결정 |
|---|---|
| 출시 | 구글 플레이, 실제 결제와 광고 |
| 재화 | 유료 다이아(서버 장부)와 무료 보석·게임 재화를 분리 |
| 과금 균형 | 무과금도 막히지 않고, 결제자가 지나치게 앞서가지도 않게 계산(12장 기준) |
| 화면 | 세로 고정. 폰 화면 기준, 태블릿·PC는 같은 세로 화면을 가운데에 |
| 환생 | 넣음(이 문서에서는 "철수"라고 부름). 횟수에 따라 자동화가 열림 |
| 사람 도트 | SD 비율 유지, 새로 그려 퀄리티 상향 |
| 기지 | 벙커 위 쉘터. 업그레이드하면 실제로 커지고, 구역·터렛·수리공이 생김 |
| 외형 | 10레벨 돌파마다 크게 바뀜. 시대: 임시 → 군용 → 미래 |
| 굶주림 | 저장을 지우지 않음. 식량이 모자라면 동료 성장이 막히고, 굶는 중에 뚫리면 강제 철수(훈장 절반, 스테이지 50 전에는 한 칸 후퇴만) |
| 템포 | 업그레이드와 등반이 자주. 스테이지 60대까지 몇 시간인 지금 속도는 유지 |
| 연출 기준 | Pixel Composer 쇼케이스 수준의 도트 효과와 애니메이션 |

## 2. 대상 기기와 화면 규격 (구글 플레이 기준)

**기준 화면:** 360×800dp(20:9, 1080×2400 기기, 가장 흔한 안드로이드).

**지원 범위 (세로 고정)**

| 구분 | 크기(dp) | 대표 기기 |
|---|---|---|
| 작은 폰 | 360×640 | 구형 |
| 보통 폰 | 360×780 / 360×800 / 384×854 / 393×873 | 갤럭시 S·A, 픽셀 |
| 큰 폰 | 412×915 | — |
| 폴더블 커버 | 약 344×882 | — |
| 펼친 폴더블·태블릿 | — | 게임 화면을 가운데 최대 480dp, 양옆은 배경 |

**안전 영역:** 안드로이드 15(API 35) 타깃 앱은 화면 끝까지 그리기(edge-to-edge)가 강제되고, 구글 플레이는 최신 API 타깃을 요구합니다. 상태바, 펀치홀, 제스처 바는 `env(safe-area-inset-*)`(viewport-fit=cover)로 피합니다.

**게임 화면 배율**
- 기기 픽셀 너비를 정수 k로 나눠, 게임 내부 너비가 약 270~300px가 되게 합니다(1080px → k=4 → 270, 1440px → k=5 → 288, 720px → k=3 → 240).
- 도트가 항상 정수배라 선명하고, 지금보다 사람과 기지가 약 1.4배 크게 보입니다.
- 지상과 지하는 같은 k를 써서 크기 불일치를 없앱니다.
- 기지가 시대를 넘어 커지면 카메라가 한 단계 물러납니다(k−1). 두 번 탭하면 가까이/멀리를 바꿉니다.

**UI 크기 규칙**
- 터치 대상은 최소 48dp입니다.
- 글자는 본문 13sp, 숫자 14sp 굵게, 보조 11sp.
- 한글 도트 글꼴은 **갈무리(Galmuri, OFL 1.1, 상업 사용 가능)**입니다. npm으로 받을 수 있는 것을 확인했고, 자주 쓰는 2,350자로 줄입니다.

## 3. 게임의 기둥

1. **계속 오르는 성장(인크리멘탈):** 둔해질 즈음 새 성장 층이 열립니다.
2. **모으는 재미:** 무기, 터렛, 유물, 동료가 맞물립니다.
3. **커지는 쉘터:** 업그레이드가 눈에 보입니다.
4. **편한 방치:** 오프라인, 자동화, 절전 모드.
5. **비교와 경쟁:** 기지 털기, 랭킹.
6. **감성:** 도트, 애니메이션, 효과, 사운드를 상업 수준으로.

## 4. 재화와 흐름 (남아도는 재화가 없게)

| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 금화 | 처치, 스테이지 | 공방 강화(철수 때 초기화), 동료 레벨, 구역 레벨 |
| 식량 | 2층 식량 | 동료 유지비(레벨 비례), 동료 돌파, 침실·벙커 돌파, 습격 |
| 광물 | 3층 채굴 | 돌파, 장비 돌파, 터렛 |
| 부품 | 작업장(지상), 처치 0.1개·보스 20개, 중복 분해 | 장비 강화 돌파, 수리(1% 수리에 1개), 동료 돌파 |
| 지휘관 경험치 | 처치, 클리어, 보스 | 지휘관 레벨 |
| 보석(무료) | 보스 첫 클리어 50, 타이탄 500, 일일 300, 철수 보상, 광고 | 뽑기 |
| 다이아(유료) | 결제 | 뽑기(보석과 1:1), 연구 단축, 습격권, 꾸미기, 월정액 |
| 훈장 | 철수 | 훈장 강화 |
| 명성 | 습격 | 습격 상점, 리그 |
| 유물 조각 | 최대 레벨 유물의 중복 | 유물 선택, 각성 |

**넘치지 않게 하는 장치**
- 창고 상한은 "구역 생산 1시간 × (1+0.15×용량 레벨)"입니다.
- 돌파 비용은 창고의 80%를 넘지 않습니다. 넘으면 영원히 못 사는 교착이 생기기 때문입니다.
- 창고를 넘친 재화는 10:1로 경험치가 됩니다(유물 "연금술 화로"를 끼면 금화).

## 5. 성장 층 (인크리멘탈)

| 층 | 열림 | 곱하는 대상 | 초기화 |
|---|---|---|---|
| 1. 공방(금화 강화) | 처음 | 무기 기본 피해, 연사, 탄창, 장전 | 철수 때 |
| 2. 지휘관 레벨 | 스테이지 10 | 자기 스탯 배율 | 없음 |
| 3. 훈장 | 스테이지 50 보스 뒤 첫 철수 | 화력 ×1.15/레벨, 군자금 ×1.15/레벨 등 | 유지 |
| 4. 연구소(지하 4층) | 기록 1,000 | 탄도학 ×1.3/레벨(연구 시간 2×레벨 시간), 교리(훈장 상한 상승) | 없음. 다이아로 시간 단축 가능 |

**철수(환생)**
- **초기화:** 스테이지, 금화·식량·광물, 공방 강화.
- **유지:** 벙커·울타리·구역(기지는 남음), 장비, 유물, 동료, 지휘관 레벨, 훈장, 연구, 자동화.
- **철수 횟수 자동화 (번거로움 제거):**

| 횟수 | 열리는 것 |
|---|---|
| 1회 | 공방 자동 강화 |
| 3회 | 자동 돌파 |
| 5회 | 시작 스테이지 건너뛰기 |
| 8회 | 자동 합성 |
| 12회 | 자동 스킵 기준을 10배에서 5배로 |
| 20회 | 목표 배수에 닿으면 자동 철수 |

  자동 강화가 쓸 금화 비율은 막대로 정합니다.

**지휘관 레벨**
- **경험치:** 처치당 1+s/20, 클리어당 5+s/5, 보스 50+s.
- **레벨업:** 60·ℓ^1.5 경험치가 필요하고, 레벨마다 3포인트를 받습니다.
- **스탯(모두 최종값에 곱함):**
  - 위력: 피해 ×(1+0.03p)
  - 속사: 연사 ×(1+0.01p)
  - 행운: 금화 ×(1+0.03p)
  - 정밀: 치명 피해 +2%·p
  - 지휘: 동료·터렛 ×(1+0.03p)
  - 보급: 생산 ×(1+0.02p)

## 6. 스테이지

**난이도 지수 (10,000 이상까지 숫자가 터지지 않게)**
- H(s) = 20(√(1+s/200) − 1) + e·min(s,100). e는 초반 속도 조절 값이고, 시안은 0.012입니다.
- 이 값으로 좀비 체력 20·10^H, 공격 4·10^(0.7H), 처치 금화 3·10^(0.8H)를 정합니다.
- **숫자 상한:** 스테이지는 약 30,000에서 막습니다. 표기는 aa~zz까지 늘립니다.

**스테이지 진행**
- 처치 수는 30 + min(30, s/10)입니다. 한 스테이지 30~60초로 자주 등반합니다.
- **보스:** 10스테이지마다. 체력 400배, 제한시간 45초, 고유 패턴.
- **타이탄:** 100스테이지마다. 체력 1,000배, 3단계, 유물 확정, 보석 500.
- **실패:** 시간 초과나 벙커 파괴면 한 스테이지 뒤에서 반복 모드가 됩니다.
- **자동 스킵:** 진행 모드에서 화력이 다음 스테이지 필요량의 10배 이상이면 최대 50스테이지를 건너뜁니다. 재등반을 빠르게 하는 장치입니다.
- **선택기:** `◀ 스테이지 64 ▶`. 깬 범위 안에서 오갑니다. 창에서 반복/진행과 최근 2분 실측 분당 수익을 봅니다.

**구간 (구간마다 2~3종만, 보스 고유 패턴)**

| 스테이지 | 주제 | 좀비 | 보스: 패턴 |
|---|---|---|---|
| 1~10 | 외곽 | 워커, 크롤러 | 도살자: 12초마다 울타리 돌진 3회 |
| 11~20 | 고속도로 | 러너, 워커 | 폭주떼: 8초마다 러너 무리 |
| 21~30 | 병원 | 부푼 놈, 침 뱉는 놈 | 역병 의사: 산성 웅덩이로 터렛 정지 |
| 31~40 | 경찰서 | 장갑 좀비, 덩치 | 진압 거상: 정면 장갑 90%, 관통이나 측면 사격 필요 |
| 41~50 | 지하철 | 굴 파는 놈, 크롤러 | 굴의 어미: 울타리 안쪽에서 솟아남 |
| 51~60 | 공장 | 덩치, 비명 지르는 놈 | 울부짖는 자: 15초마다 좀비 속도 +60% |
| 61~70 | 숲 | 뛰는 놈, 러너 | 도약 왕: 지붕에 착지해 사수 기절 |
| 71~80 | 연구소 | 재생하는 놈, 부푼 놈 | 히드라 덩어리: 불타지 않으면 초당 3% 재생 |
| 81~90 | 부두 | 거인, 침 뱉는 놈 | 산성 여왕: 5초간 터렛 정지 |
| 91~100 | 폐허 | 거인, 장갑 좀비, 비명 지르는 놈 | 타이탄: 체력 50%에서 셋으로 분열 |
| 101~ | 지대 반복 | 같은 조합 + 새 색 + 정예 특성(10%→40%) | 지대마다 패턴 하나 추가 |

**보스 연출**
- 기본 좀비의 2.5~3배 크기로 그립니다(96~128px).
- 등장할 때 화면 흔들림, 경고 띠, 전용 음악, 화면 위 큰 체력 막대가 나옵니다.

## 7. 장비

**무기 (뽑기로만) — 8등급 × 등급마다 5자루 = 40자루, 순서대로 올라감**
- **등급:** 일반(회색) → 고급(초록) → 희귀(파랑) → 영웅(보라) → 전설(주황) → 불멸(빨강) → 신화(금색) → 영원(무지개 빛). 등급이 높을수록 카드 테두리와 빛 연출이 화려해집니다.
- **순서:** 등급마다 1~5번 무기가 있고, 일반 1 → 일반 5 → 고급 1 … → 영원 5 순서로 강해집니다.
- **합성:** 같은 무기 4개를 합치면 다음 순번 무기 1개가 됩니다(일반 5 ×4 → 고급 1). 낮은 등급을 뽑아 합쳐 올라가는 구조라 운보다 꾸준함이 중요합니다. 합성 개수(4~5)는 시뮬로 정합니다.
- **뽑기 확률(소환 레벨 1):** 일반 52% / 고급 30% / 희귀 12% / 영웅 4.5% / 전설 1.2% / 불멸 0.25% / 신화 0.045% / 영원 0.005%.
  - 뽑을수록 소환 레벨(1~20)이 오르고, 높은 등급 확률이 조금씩 오릅니다. 이것도 성장 축입니다.
- **천장:** 영웅 이상은 50회, 전설 이상은 150회, 불멸 이상은 500회 안에 보장합니다. 신화·영원은 주로 합성으로 얻습니다.
- **효과:**
  - 장착 효과: 무기를 든 사람의 공격 % 배율, 계열 특성.
  - 보유 효과: 가진 무기마다 전체 공격 %가 쌓여서, 모으는 것 자체가 성장입니다.
  - 순번이 하나 오를 때마다 배율이 일정하게 오릅니다. 등급 하나는 순번 5칸이라 단계가 촘촘합니다. 배율은 시뮬로 정합니다.
- **강화:** 무기마다 레벨이 있고, 상한은 등급이 높을수록 높습니다(일반 20 → 영원 160). 비용은 금화·부품이고, 10레벨마다 광물·부품 돌파가 필요합니다.

## 8. 동료와 쉘터 구역

**동료 카드 (첫 출시 24명: 8등급 × 3명, 아래는 일부. 1단계에서 전체 확정)**

| 등급 | 동료 |
|---|---|
| 주인공 | 나 |
| 기본 | 민준(사수, 피해 +10%), 서연(농부, 식량 +25%), 도윤(사수, 치명 +8%), 하은(농부, 유지비 −10%), 지호(광부, 광물 +30%) |
| 희귀 | 수아(수리공, 수리 1.5배, 터렛 부활), 태오(사수, 관통 +1, 저격 +30%), 준혁(광부, 유물 발견 +15%) |

- **레벨:** 금화 100·1.12^ℓ. 10레벨 돌파마다 식량 60k²과 부품 15k²이 듭니다.
- **별:** 중복으로 ★1~5, 별마다 능력 +20%.
- **사수 피해:** 지붕에 배치된 동료는 ×(1+0.04ℓ).
- **유지비:** 0.3·(1+0.1ℓ) 식량/초. 식량 생산이 새 유지비의 1.15배보다 적으면 레벨업이 잠깁니다. 성장만 멈추고, 시작부터 굶지는 않습니다.
- **대표 캐릭터:** 프로필·랭킹·습격 대장이고 스탯 +10%입니다.
- **배치:** 구역에 들어가 "+ 일꾼 배치"로 넣습니다. 사람마다 직업 버튼을 누르는 방식은 없앱니다.

**구역 (각 구역에 레벨·등급·용량 세 갈래)**
- **레벨:** 금화, 생산 +4%/레벨.
- **등급:** 보조 재화 200·T². 생산 +10%(지붕은 피해 +20%)와 외형 변화.
- **용량:** 창고 상한.

|---|---|---|---|---|
| 지붕 초소 | 사수 2→6 | 총좌 | 탄약고 | 거리 측정기(치명) |

| 3층 채굴 | 1→5 | 곡괭이 | 광차 | 드릴 |
| 4층 연구소 | 연구원 | 실험대 | 자료실 | 장비 |

- **일꾼 1명당 생산:** 식량 2, 광물 1.5, 부품 1(초당) × (1+0.1T)(1+0.04L).

**기지 크기**
- 벙커 레벨 1/11/31/61/91에 지붕 사수 칸이 늘어납니다. 시대가 바뀌면 벙커 크기와 지붕이 커집니다.
- 지하는 층이 늘고, 침실은 인원만큼 침대를 제대로 놓습니다.

## 9. 기지 털기와 랭킹 (서버)

- **기지 기록:** 철수할 때와 하루 한 번, 내 기지 요약(2KB 미만)을 올립니다: 전투력, 기록, 벙커·울타리, 터렛, 방어 동료 3명과 장비·유물, 대표.
- **상대 고르기:** 서버가 전투력 ±25%에서 3명을 골라줍니다.
- **전투:** 같은 시드로 결과가 정해지는 60초 자동 전투입니다. 화면에서 재생하고, 서버가 다시 계산해 검증한 뒤 보상합니다.
- **보상:** 습격 점수(리그), 부품, 전투 식량.
  - 털린 쪽은 아무것도 잃지 않고 방어 기록과 복수 버튼을 받습니다. 방치하는 동안 털려서 손해 보는 불만을 막기 위해서입니다.
  - 습격권은 하루 5장이고, 습격마다 식량이 듭니다. 넘치는 후반 식량을 쓰는 곳이 됩니다.
- **랭킹:** 주간 습격 리그, 최고 기록, 전투력. 서버는 기록·철수 횟수·계정 나이로 정한 상한을 넘는 전투력을 거부합니다.

## 12. 과금과 무과금 균형

**원칙**
- 다이아는 시간을 줄여 주지만 다른 축을 열어 주지 않습니다. 훈장·스탯 포인트는 팔지 않고, 모든 콘텐츠는 무과금으로도 얻습니다.
- 천장이 있어서 운이 나빠도 끝없이 막히지 않습니다.

**시뮬에 넣을 세 유형과 합격 기준**

| 유형 | 지출 | 스테이지 1,000 도달 시간(무과금 대비) |
|---|---|---|
| 무과금 | 0원, 보석(활동 1시간당 600~1,000 + 일일 300) + 광고 | 기준 |
| 소과금 | 월정액 5,500원 + 시즌 패스 9,900원 | 15~25% 빠름 |
| 고과금 | 월 10만 원 | 35~45% 빠름. 그 이상 써도 효용이 급격히 줄어듦 |

- 무과금이 활동 중에 30분 이상 아무것도 못 사거나 못 오르는 구간이 없어야 합니다.
- 습격 리그는 전투력 ±25%로 짝을 지어 고과금이 무과금을 일방적으로 털지 않게 합니다.

**수집은 스트레스 없이**
- 천장, 중복을 합성 재료로 쓰는 구조, 합성 사다리 덕분에 운이 나빠도 꾸준히 오릅니다.
- 한정 뽑기로 조급하게 만드는 상술은 쓰지 않습니다(놓치면 영영 못 얻는 무기·동료 없음).
- 뽑기 결과 화면에서 "다음 합성까지 n개"를 보여줘서 헛뽑기 느낌을 줄입니다.

| 장비 프리셋 | 무기·유물 조합 저장 칸 |

| 배속 상시 | x2 배속을 기본값으로 |

- 힘을 직접 파는 것은 아래 성장 패키지에만 있고, 그것도 스테이지 조건으로 순서대로 열려서 너무 앞서가지 않게 합니다.

**단계별 성장 패키지 (하나 사면 다음 단계가 열림)**

| 단계 | 가격 | 구성(예) | 열리는 조건 |

**실제 동작 검증 (참고 자료가 유명해도 그대로 믿지 않음)**
- **권총:** 두 손 파지. 사격 손은 손잡이 높게, 보조 손이 감쌉니다.
- **소총:** 사격 손은 손잡이, 보조 손은 총열 덮개 아래, 개머리판은 어깨에 붙입니다.
- **산탄총:** 펌프질은 총열 축을 따라 앞뒤 직선으로 하고, 손은 펌프에서 떨어지지 않습니다.
- **반동:** 총구가 총열 축을 따라 뒤로 밀리며 들렸다 돌아옵니다. 옆으로 튀지 않습니다.
- **장전:** 탄창 분리 → 빼기 → 새 탄창을 조끼·벨트에서 꺼내기 → 끼우고 밀어 넣기 → 장전 손잡이나 슬라이드. 손이 실제 부품을 따라갑니다.
- **총은 단단한 물체:** 모든 프레임에서 길이와 잡는 위치가 같습니다. 손과 몸이 총을 뚫지 않고, 총구 좌표는 그린 총구 끝과 일치합니다.
- **망치·곡괭이·괭이:** 휘두른 뒤에도 손목과 손이 자루를 쥔 채 따라갑니다. 휘두르는 축은 어깨와 팔꿈치입니다.

## 14. 연출과 효과(VFX)

**참고 자료와 방법**

  - **색 버퍼 + 빛 버퍼:** 빛(더해지는 발광)을 따로 그려서 불빛이 빛처럼 보이게 합니다.

- **조정할 것:** 봇은 60까지 0.3시간이지만, "60대까지 몇 시간"인 지금 속도를 유지하기로 했습니다. 초반 값(e)을 올려 실제 플레이 기준 2~3시간에 맞추고 다시 검증합니다.
- **하루 1.5~2시간 플레이 기준:** 스테이지 1,000은 2~3주, 10,000은 4~6개월입니다.

**배율 겹침표 (각 축이 주는 배수)**

| 축 | 스테이지 100 | 500 | 1,000 |
|---|---|---|---|
| 공방 공격력 | 7.1e3 | 7.7e10 | 5.3e16 |
| 연사×가동률 | 4.4 | 19 | 41 |
| 무기 % | 4.0 | 8.7 | 14 |
| 사수+터렛 수 | 3 | 6 | 11 |
| 동료 카드 | 3.0 | 15 | 25 |
| 지붕 구역 | 2.2 | 16 | 46 |
| 지휘관 레벨 | 1.8 | 5.8 | 11 |
| 훈장 | 1.7 | 310 | 3.1e6 |
| 유물 | 1.6 | 2.7 | 7.4 |

  로그 기준으로 공방이 전체 힘의 약 54%, 훈장은 3%→20%, 나머지는 각각 3~9%입니다. 폭발하는 축도, 쓸모없는 축도 없습니다.

**재화 수급**
- 광물과 부품은 오프라인 생산까지 다 쓰입니다.
- 식량은 기록 1,000 이후 20~27% 넘칩니다. 습격 식량과 연구 식량 비용으로 흡수합니다.

**훈장 공식:** ⌊10·10^(0.55·(H(최고) − H(50)))⌋. 한 번 철수로 보유 훈장이 두 배를 넘지 않게 상한을 둡니다. 상한이 없으면 지수 0.45에서 3,000 근처에 정체하고, 0.55에서는 39시간에 10,000에 닿을 만큼 민감하기 때문입니다.

**1단계에서 할 일**
- 이 모델을 `bunker/tests/sim`으로 옮깁니다.
- 과금 유형 세 가지(12장)와 실제 사람 플레이에 가까운 봇(덜 최적)을 추가합니다.
- 12장과 아래 합격 기준을 모두 통과할 때까지 조정합니다.

**합격 기준**
- 스테이지 60대는 실제 플레이 2~3시간입니다.
- 강화 구매는 평균 1분 이내 간격, 스테이지 클리어는 30~60초입니다.
- 창고가 가득 찬 시간은 재화마다 5% 이하입니다.
- 무과금이 30분 이상 막히는 구간이 없습니다.
- 과금 효용이 12장 범위 안에 있습니다.

## 20. 검증

- **단위 테스트(node, `src/logic`):** 공식, 능력치 계산, 저장 v4→v5 변환, 뽑기 확률·천장(10만 회 표본), 합성, 습격 전투 결정성(같은 시드는 같은 결과).

  - HUD 겹침·글자 잘림·터치 대상 48dp 자동 검사
  - 지상·지하 사람 크기가 같은지, 총구·불꽃 좌표가 프레임마다 맞는지
- **도트 검사 시트:** 방향·동작별로 반대편 다리·고관절 노출을 확인하고, 단계별 건물 격자를 봅니다.

- **단계마다:** 별도 에이전트로 적대적 검토를 하고, 재현된 문제만 고칩니다.
