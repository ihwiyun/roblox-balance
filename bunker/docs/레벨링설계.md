# 레벨링 설계 (주 단위, 확인용 초안 2)

기준은 무과금이고, 하루 4번(1번에 약 26분, 하루 1시간 45분) 접속하는 사람입니다.

## 1. 지금 시뮬에서 실제로 일어나는 일 (`tests/sim/timeline.md`, 12주)

| 문제 | 숫자 |
|---|---|
| 해금이 첫날에 몰림 | 채굴·지휘관·작업장·터렛 칸 1~3·유물 칸 1~2·자동화 4개가 1~3일 안에 열림. 2~4주에는 새로 열리는 게 거의 없음 |
| 환생이 너무 잦음 | 12주에 114번(주 10번). 7주차부터 활동의 66~74%가 이미 깬 스테이지 재등반 |
| 무기 사다리가 빨리 끝남 | 무과금이 37일째 영원 등급. 6주 뒤로는 모을 게 없음 |
| 수집 장비가 힘에 거의 안 들어감 | 공방 56%, 훈장 13%. 무기 7~10%, 유물 1%, 터렛 0~1%. 그래서 과금 효과가 8~16%뿐 |
| 원인 | 연산식에서 공방은 레벨당 ×1.10으로 끝없이 지수 성장하는데, 무기는 40단계를 다 올라도 ×41(단계당 ×1.10)뿐이고 유물은 대부분 작은 % 하나씩이라 비중이 안 나옴 |

## 2. 공격력 연산식 (다시 세운 것)

### 2-1. 사수 한 명

```
공격력  = 기본 공격력 × 무기 배율 × (1 + 공격력 % 합) × 곱 배율
초당 피해 = 공격력 × 초당 발사 수 × 치명 기대값
```

**기본 공격력:** 공방 '공격력' 레벨로 오릅니다. 금화를 쓰고, 레벨당 ×1.07입니다. 환생하면 처음으로 돌아갑니다.

**무기 배율:** 단계 배율 × (1 + 강화 레벨 × 5%)
- 단계 배율은 단계마다 ×1.3입니다. 40단계를 다 오르면 약 ×2.8만입니다.
- 강화 상한은 등급이 높을수록 높습니다(일반 20 ~ 영원 160). 그 사람이 든 무기에만 적용됩니다.

**공격력 % 합 (더하는 묶음):** 아래를 다 더합니다.
- 무기 보유 효과의 합: 가진 무기마다 +%이고, 높은 단계일수록 큽니다.
- 터렛 보유 효과
- 도감: 처음 가진 무기마다 +1%, 등급 하나를 다 모으면 +10%
- 유물의 공격력 %
- 세트 효과
- 동료 능력(구역에 있을 때, 별마다 +20%)과 대표 +10%

**곱 배율 (곱하는 묶음):**

| 항목 | 배율 |
|---|---|
| 훈장 화력 | 레벨당 ×1.15 |
| 지휘관 | ×(1 + 0.02 × 레벨) |
| 연구 탄도학 | 레벨당 ×1.3 |
| 지붕 구역 | ×(1 + 0.04 × 레벨) × (1 + 0.2 × 등급) |
| 동료 레벨 | 그 사람만 ×(1 + 0.04 × 레벨) |
| 유물 공명 | 장착한 유물 레벨 합 1당 ×1.1 |

**초당 발사 수:** 공방 연사 × (1 + 연사 %) × 가동률(탄창 ÷ (탄창 + 장전 시간))
- 초당 12발이 상한입니다. 넘는 연사는 피해로 바뀝니다.

**치명 기대값:** 1 + 치명 확률 × (치명 피해 − 1)

| | 기본 | 더해지는 것 | 상한 |
|---|---|---|---|
| 치명 확률 | 5% | 권총 계열 +10%, 지붕 거리측정기, 유물, 동료 | 80% |
| 치명 피해 | 150% | 저격 계열 +30%, 유물, 세트 | — |

### 2-2. 터렛 한 기

```
초당 피해 = 기본 공격력 × 터렛 배율 × (1 + 터렛 % 합) × (훈장 × 지휘관 × 연구 공학) × 역할 계수 × 초당 발사 수
```

- **터렛 배율:** 무기와 같은 사다리입니다(단계마다 ×1.3, 강화 레벨 × 5%).
- **역할 계수**

| 역할 | 특징 |
|---|---|
| 기관포 | 단일 1.0 |
| 화염 | 화상(재생을 막음) |
| 냉각 | 느려짐 |
| 전기 | 연쇄 3마리 |
| 폭발 | 범위(무리·분열에 강함) |

- **목표:** 터렛이 전체 초당 피해의 25~35%를 냅니다.

### 2-3. 전체와 보스

```
전체 초당 피해 = 사수 합 + 터렛 합
```

- **일반 스테이지(무리):** 범위 보정이 붙습니다. 산탄, 폭발, 연쇄, 군집 % 효과입니다.
- **보스:** × (1 + 보스 피해 %) × 패턴 보정입니다. 보스 패턴마다 막는 수단이 정해져 있습니다.

| 보스 패턴 | 막는 수단 |
|---|---|
| 정면 장갑 90% | 관통 비율만큼 상쇄(저격, 관통탄, 철갑 코어, 동료 태오·레아) |
| 재생 초당 3% | 화상 가동률만큼 상쇄(화염 터렛, 인, 네이팜, 화염 무기) |
| 분열 | 범위 비율만큼 상쇄(폭발 터렛, 산탄, 연쇄) |
| 터렛 정지 | 저항(방독면, 동료 수아·세라) |
| 사수 기절 | 저항 |

### 2-4. 상호작용 (전부)

| 종류 | 내용 |
|---|---|
| 원소 반응(장착한 유물, 무기, 터렛의 원소로 성립) | 불+얼음: 냉각된 불타는 대상 +100% / 얼음+전기: 연쇄 2배 / 불+전기: 화상이 연쇄를 따라 퍼짐 / 관통+치명: 관통 1명당 치명 +1% |
| 세트 3개 | 검은 연기(불탄 처치 폭발), 동상(빙결 대상 치명 2배), 폭풍(연쇄 +2), 사냥꾼(처치 시 장전 −20%), 성채(울타리 재생 2배), 보급관(돌파 비용 −15%) |
| 무기 계열 | 권총: 치명 / 소총: 연사 / 산탄: 무리 / 저격: 관통·치명 피해 / 중화기: 범위·화상 |
| 동료 능력 | 자기 구역에 있을 때만 적용, 대표는 +10% |
| 방어 | 울타리 → 벙커 순으로 맞음. 수리공이 초당 최대 체력 0.4%를 고침. 장갑판·거울 파편은 받는 피해를 줄임 |

### 2-5. 성장 법칙과 12주차 비중 목표 (무과금, 로그 기준)

| 항목 | 무엇으로 오르나 | 성장 | 12주차 비중 |
|---|---|---|---|
| 기본 공격력(공방) | 금화 | 레벨당 ×1.07 (지금 ×1.10) | 30~35% (지금 56%) |
| 훈장 | 환생 | 화력 레벨당 ×1.15 | 15~20% |
| 무기(장착·강화·보유·도감) | 뽑기·합성·강화 | 단계당 ×1.3 (지금 ×1.10) | 15% (지금 7%) |
| 터렛 | 뽑기·합성·강화 | 단계당 ×1.3 | 8~10% (지금 0~1%) |
| 유물 | 드랍·상자·시즌 패스 | 공명 레벨당 ×1.1 + 효과 | 8~10% (지금 1%) |
| 지붕·동료·지휘관·연구·연사·치명 | 여러 가지 | 대체로 선형 | 약 15% |

## 4. 무기 등급과 결제

### 등급 안 번호
1이 가장 좋고 5가 가장 낮습니다. 오르는 순서는 일반 5 → … → 일반 1 → 고급 5 → … → 전설 5 → 전설 1 → 불멸 5 … 입니다. 같은 무기 4개를 합치면 바로 위 번호가 됩니다.

### 패키지는 전설 3까지만 팝니다 (더 이르게 열림)

| 단계 | 가격 | 구성 | 열림 |
|---|---|---|---|
| 1 | 1,200원 | 희귀 3 + 보석 300 | 처음부터 |
| 2 | 3,300원 | 영웅 5 + 희귀 동료 카드 | 스테이지 10 |
| 3 | 5,900원 | 영웅 3 + 유물 상자 5 | 스테이지 30 |
| 4 | 12,000원 | 전설 5 + 영웅 터렛 | 스테이지 60 |
| 5 | 33,000원 | 전설 4 + 전설 동료 카드 | 스테이지 150 |
| 6 | 69,000원 | 전설 3 + 유물 상자 30 | 스테이지 300 |

불멸 이상은 팔지 않습니다. 뽑기와 합성으로만 얻습니다.

### 등급별 첫 무기 시점

| 등급 | 무과금 | 고과금 |
|---|---|---|
| 희귀 | 2일 | 1일(1단계) |
| 영웅 | 1주 | 1일(2단계, 스테이지 10) |
| 전설 | 3주 | 1일(4단계, 스테이지 60), 전설 3은 1주(6단계, 스테이지 300) |
| 불멸 | 8주 | 3~4주(합성·뽑기) |
| 신화 | 12주 이후 | 8주 |
| 영원 | 수개월 | 12주 이후 |

### 과금 차이 목표
- **소과금:** 15~25% 빠름. 월정액은 매일 보석(뽑기 1회분)과 광고 없는 보상, 오프라인 +2시간입니다. 시즌 패스는 보석과 유물 상자입니다.
- **고과금:** 35~45% 빠름. 수집 장비가 힘의 약 35%라서, 일찍 받은 전설 무기와 많이 뽑은 장비가 실제 속도 차이로 이어집니다.

## 5. 이렇게 맞추려고 바꿀 수치 (밸런스 담당)

| 항목 | 지금 | 바꿀 값 |
|---|---|---|
| 연산식 | 무기 단계 ×1.10, 공방 ×1.10 | 2장대로: 무기·터렛 단계 ×1.3, 강화 5%, 공방 레벨당 ×1.07, 유물 공명, 터렛이 피해의 25~35% |
| 유물 칸 해금 | 스테이지 20/50/100/200/400/700/1,000/2,000 | 스테이지 20/100/250/450/650/850/1,150/1,450 |
| 터렛 칸 해금 | 벙커 레벨 25/50/100/200/400/700 | 스테이지 30/150/350/550/1,000/1,300 |
| 뽑기 가격 | 무기 50 | 승인된 설계도대로 무기 100, 터렛 150, 유물 300, 동료 200 |
| 무료 보석 | 무과금이 주 160~200회 뽑음 | 무과금 무기 등급 시점이 4장 표에 맞게 |
| 환생 | 주 10번 | 훈장 공식·상한으로 3장의 횟수에 맞게 |
| 다시 치는 시간 | 활동의 66~74% | 자동 스킵으로 35% 이하 |

나머지 기준(구매 간격 1분 이내, 창고 가득 5% 이하, 30분 이상 막힘 없음)은 그대로입니다.

## 6. 보고
- 주차별 표에 설계 목표와 실제(무과금, 소과금, 고과금)를 나란히 놓습니다. 해금 시점, 환생 횟수, 힘 구성도 함께 적습니다.
- 그래프의 가로축은 주이고, 해금이 일어난 시점을 표시합니다.
