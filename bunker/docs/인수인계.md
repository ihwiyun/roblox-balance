    - 지휘관 포인트를 안 씀(고쳤음)

## 3. 확정된 결정 (사용자 답변)

**외형 성장**
- 50레벨마다 돌파(재료+금화)가 있고, 돌파 때 부품 하나 또는 재질·색 등급이 바뀝니다.
- 돌파 25번마다 시대가 바뀝니다.
- 단계 수에는 끝이 없습니다. 손으로 그린 단계가 끝나면 재질 등급(청동 → 은 → 금 → 백금 …)으로 이어 갑니다.
- 부품 목록은 기획서 8장에 있습니다. 돌파 판정은 `bunkerBreak`, `fenceBreak`, `facBreak`가 하고, 조건은 `L > 0 && L % 50 === 0`입니다.

**화면**
- 승인된 설계도 배치에 아래 지적을 대입하고 강약을 조절합니다(이번 차례 계획).
- **아래 탭:** 5개입니다. 강화 · 장비 · 캐릭터 · 기지 · 상점이고, 유물은 장비 안의 탭으로 들어갑니다.
- **장착 위치**

| 장비 | 장착하는 곳 |
|---|---|
| 무기 | 캐릭터 화면(인물이 서 있고 옆에 무기 칸) |
| 터렛 | 기지의 터렛 칸 |
| 유물 | 장비 → 유물 탭 |

- **장비 화면:** 보관함입니다. 등급별 칸, 합성·강화, 도감이 있습니다.
- **뽑기:** 각 화면 안에 둡니다. 무기·터렛·유물 뽑기는 장비에, 동료 모집은 캐릭터에 있습니다.
- **상점:** 돈 쓰는 곳만 둡니다. 패키지 · 다이아 · 편의·패스입니다.
- **아이콘**
  - 보석은 루비(빨강) 아이콘으로 바꿉니다. 광물 아이콘은 그대로 둡니다.
  - 설정·환생·랭킹은 32 크기 도트 아이콘으로 만듭니다(글자 상자 금지).
  - x1·x5·x10·MAX는 작은 칩으로 만듭니다.
- **강약 규칙**
  - 주요 버튼은 검정으로 채우고 화면에 하나만 둡니다.
  - 보조 버튼은 테두리만 둡니다.
  - 칩은 작게 하고, 누르는 영역만 48로 잡습니다.
  - 등급색은 등급 표시에만 씁니다.
- **초상화:** 48×48 흉상을 손으로 새로 그립니다. 게임 그림을 잘라 쓰지 않습니다. 견본 2장(나, 민준)을 먼저 그립니다.
- **카메라**
  - 지금보다 한 단계 확대합니다. 땅이 너무 작습니다.
  - 기지가 커지면 한 단계씩 뒤로 물러납니다.
  - 정수 배율만 씁니다.

**기타**
- **용어:** 스테이지라고 부릅니다(설계도). 환생은 환생입니다(철수 아님).
- **결제:** 편의성 위주로 유도합니다. 단계 패키지 1단계는 1,200원에 희귀 5번 무기입니다.
- **수집:** 무기 8등급 × 5, 터렛 32, 유물 48, 동료 24입니다.
- **창고:** 식량·광물 창고 상한은 업그레이드합니다. 금화는 상한이 없습니다.

## 5. 다시 시작할 때 쓰는 에이전트 지시 요점

모든 에이전트에 공통으로 적용합니다.
- 지침(`CLAUDE.md`)을 따릅니다.
- 자기 파일만 고치고, 커밋은 하지 않습니다.
- 견본에서 멈추고, 첫 그림이 나오면 메인에 경로를 보냅니다.

| 에이전트 | 맡은 파일 | 견본 범위 |
|---|---|---|
| 벙커·울타리 | `src/yard.js`, `src/buildings.js` | 레벨 1(그대로), 50~400(돌파 8번), 1,250(시대 전환). 부품 × 단계 표. 사수 6명 얼굴이 보이게. 터렛 거치대는 25/50/100/200/400/700 |
| 지하 | `src/under.js`, `src/facilities.js` | 채굴이 우선. 1, 50~400, 1,250. 식량·침실은 1~200, 1,250. 일꾼이 기계 안에 서지 않게 |
| 사운드 | `audio/**` | CC0만. 듣기 페이지 `audio/index.html`. 게임에는 아직 연결하지 않음 |
| 초상화 | 초상화 그림 파일 | 견본 2장 |

렌더는 커밋된 상태를 따로 풀어서 찍습니다. 다른 에이전트가 고치는 중인 파일 때문에 깨지지 않게 하기 위해서입니다.

## 6. 밸런스 시뮬 쓰는 법
- `node bunker/tests/sim/run.mjs human f2p 1000 20`
  - 봇: human, greedy
  - 과금: f2p, light, heavy
  - 인자: 목표 스테이지, 일수
- 합격 기준은 기획서 18장에 있습니다.
  - 스테이지 60은 2~3시간
  - 강화 구매 간격 1분 이내, 클리어 30~60초
  - 창고 가득 5% 이하
  - 무과금이 30분 이상 막히지 않음
  - 소과금 15~25%, 고과금 35~45% 빠름
