# phone-leak-audit — 휴대폰에서 뭐가 빠져나가는지 점검하기

휴대폰의 **앱·권한·설정·통신 기록**을 훑어서 정보가 새는 경로를 찾아 주는 점검 도구입니다.

- 파이썬 파일 하나(`phone_audit.py`)이고 추가 설치할 라이브러리가 없습니다.
- 점검 결과를 **어디에도 보내지 않습니다.** 내 컴퓨터(또는 폰) 안에서만 돌고, 결과는 `report.html`로 저장됩니다.
- 폰의 설정을 바꾸지 않습니다. 읽기만 합니다.

## 무엇을 찾아내나

| 명령 | 대상 | 찾아내는 것 |
|---|---|---|
| `android` | 안드로이드 (adb 연결) | 스토어 밖에서 설치된 앱, 접근성·알림 읽기·기기 관리자 권한을 쥔 앱, 아이콘을 숨긴 앱, 문자·위치·마이크 등 민감 권한 조합, 서드파티 키보드, 프록시·프라이빗 DNS·루트 인증서(통신 가로채기), **VPN 앱과 지금 쓰는 DNS 서버**, 오래된 보안 패치, 루팅·부트로더 해제, Play 프로텍트 꺼짐, **앱별로 실제 내보낸 데이터 양**, 중국 본사 기업 앱 목록 |
| `ios` | 아이폰 (앱 개인정보 보호 리포트 파일) | 앱마다 접속한 서버 중 중국·러시아 기업 도메인과 광고·추적 서버, 위치·연락처·마이크·카메라·사진 접근 횟수 |
| `netlog` | PCAPdroid / NextDNS 기록, 도메인 목록 | 어떤 앱이 어느 나라·어느 회사 서버로 얼마나 보냈는지 |
| `checklist` | 공통 | 도구로는 볼 수 없어 직접 확인해야 하는 항목 (계정 로그인 기기, 명의도용 조회, VPN 점검 등) |

## 안드로이드 점검

### 준비 (PC가 있을 때)

1. PC에 파이썬 3과 [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)(adb)를 설치합니다.
2. 폰에서 **설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호**를 7번 눌러 개발자 옵션을 켭니다.
3. **설정 > 개발자 옵션 > USB 디버깅**을 켜고 케이블로 PC에 연결합니다.
4. 폰 화면에 뜨는 "USB 디버깅을 허용하시겠습니까?"에서 **허용**을 누릅니다.

```bash
python3 phone_audit.py android
```

1~2분 뒤 화면에 요약이 나오고 `phone-audit-report/report.html`이 생깁니다. 브라우저로 열면 표까지 볼 수 있습니다.

**점검이 끝나면 USB 디버깅을 다시 끄세요.** 켜 둔 채로 다니는 것 자체가 보안 구멍입니다.

### PC 없이 폰에서만 (Android 11 이상)

[Termux](https://f-droid.org/packages/com.termux/)(F-Droid 판)를 설치하고:

```bash
pkg install python android-tools
# 설정 > 개발자 옵션 > 무선 디버깅 > '페어링 코드로 기기 페어링'을 화면 분할로 띄운 뒤
adb pair 127.0.0.1:<페어링 포트>      # 화면의 6자리 코드 입력
adb connect 127.0.0.1:<무선 디버깅 화면의 포트>
python phone_audit.py android
```

### 스토커웨어(몰래 깔린 감시 앱) 목록 대조 — 선택

[AssoEchap/stalkerware-indicators](https://github.com/AssoEchap/stalkerware-indicators)의 `ioc.yaml`을 받아서 넘기면 알려진 스토커웨어 패키지와 대조합니다. 패키지 이름을 한 줄에 하나씩 적은 txt 파일도 됩니다.

```bash
python3 phone_audit.py android --ioc ioc.yaml
```

목록이 없어도 "비공식 설치 + 접근성 권한 + 아이콘 숨김" 조합은 자체적으로 **위험**으로 표시합니다.

### VPN을 쓰는 경우 (Tailscale, 유니콘 등)

VPN 앱은 폰의 모든 통신이 지나가는 자리라서 따로 점검합니다.

- VPN 연결을 승인받은 앱을 전부 찾아서, **스토어에서 받은 것인지**를 먼저 봅니다. 스토어 밖에서 설치된 VPN 앱은 **경고**(아이콘까지 숨겼으면 **위험**)입니다.
- Tailscale(`com.tailscale.ipn`)은 이름을 알아보고 확인할 항목(모르는 기기, 종료 노드, 공유, 키 만료)을 같이 보여 줍니다.
- 유니콘은 안드로이드 패키지 이름을 확인하지 못해서, 패키지 이름에 `lylstudio`나 `unicorn`이 들어 있으면 유니콘으로 **추정**합니다. 추정이 빗나가도 "VPN 앱"으로는 그대로 잡히고 설치 경로도 표시됩니다.
- 지금 켜져 있는 VPN이 어느 앱 것인지, 각 연결이 어떤 DNS 서버를 쓰는지 보여 줍니다(`100.100.100.100`은 Tailscale MagicDNS).
- VPN 앱은 전송량이 크게 잡히는 게 정상이라 "보낸 게 더 많은 앱" 경고에서 뺍니다.

VPN을 **켠 상태와 끈 상태에서 한 번씩** 돌려 보면 DNS와 켜진 VPN 항목이 어떻게 달라지는지 비교할 수 있습니다.

## 아이폰 점검

아이폰은 애플이 외부 도구의 접근을 막아 두어서, 애플이 직접 기록해 주는 리포트를 분석하는 방식입니다.

1. **설정 > 개인정보 보호 및 보안 > 앱 개인정보 보호 리포트**를 켭니다.
2. 평소처럼 며칠(최대 7일) 사용합니다.
3. 같은 화면 오른쪽 위 공유 버튼 > **앱 활동 저장** → `App_Privacy_Report_….ndjson` 파일이 나옵니다.
4. 그 파일을 PC로 옮겨서:

```bash
python3 phone_audit.py ios App_Privacy_Report_v4_2026-11-12.ndjson
```

리포트로 볼 수 없는 **구성 프로파일(MDM)** 은 `checklist`의 12번 항목대로 직접 확인하세요. 아이폰에서 통신을 가로채는 가장 흔한 경로입니다.

## 실제 접속 목적지 보기 (netlog)

권한 점검은 "새어 나갈 수 있는 구멍"을, 통신 기록은 "실제로 어디로 갔는지"를 보여 줍니다. 둘 다 하는 게 좋습니다.

- **PCAPdroid** (안드로이드, 루팅 불필요): 앱 실행 > 기록 시작 > 하루쯤 사용 > 연결 탭 > 메뉴 > **CSV 내보내기**
- **NextDNS** (안드로이드·아이폰): 로그 탭 > 다운로드 (접속 국가 열까지 활용합니다)
- 도메인을 한 줄에 하나씩 적은 텍스트 파일

```bash
python3 phone_audit.py netlog PCAPdroid_export.csv
```

**VPN과 같이 못 씁니다.** 안드로이드는 VPN을 한 번에 하나만 켤 수 있고 PCAPdroid도 그 자리를 씁니다. 기록하는 동안에는 Tailscale·유니콘이 꺼지므로, 기록은 VPN을 끈 평소 상태의 통신만 보여 줍니다. NextDNS를 "프라이빗 DNS"로 설정하는 방식은 VPN 자리를 쓰지 않습니다.

## 결과 읽는 법

| 등급 | 뜻 |
|---|---|
| **위험** | 통신 가로채기 설정, 스파이앱 형태의 권한 조합 등. 바로 확인하세요. |
| **경고** | 화면·알림·입력을 읽을 수 있는 강한 권한. 내가 준 권한이 맞는지 확인하세요. |
| **주의** | 그 자체로 문제는 아니지만 줄일수록 좋은 것. |
| **정보** | 참고용. |

### "중국 기업" 표시에 대해

본사가 중국에 있는 회사의 앱·도메인을 표시합니다. 중국 법은 기업에 데이터 제출을 요구할 수 있어서, 그곳으로 가는 데이터는 그 관할에 놓일 수 있다는 **정보 표시**입니다. 목록에 있다고 악성 앱이라는 뜻은 아니고, 접속했다는 사실만으로 유출이 증명되는 것도 아닙니다. 판단 기준은 "이 앱이 그 권한과 그 통신을 정말 필요로 하는가"입니다.

목록은 `phone_audit.py` 맨 위 `WATCH_PKG`, `WATCH_PREFIX`, `_CN`, `_RU`, `_TRACKER`에 있으니 직접 넣고 뺄 수 있습니다.

## 이 도구가 못 하는 것

- **암호화된 통신의 내용**은 볼 수 없습니다. "누가, 어디로, 얼마나"까지만 봅니다.
- **국가급 스파이웨어**(Pegasus 등)는 못 잡습니다. 그런 걱정이 있으면 국제앰네스티의 [MVT](https://mvt.re)를 쓰세요.
- 시스템(기본 탑재) 앱의 권한은 정상인 경우가 대부분이라 자세히 따지지 않습니다.
- "문제 없음"이 나와도 **안전 보증은 아닙니다.** 알려진 흔한 경로를 걸러 주는 도구입니다.

## 검증 상태

파서와 판정 로직은 실제 adb 출력 형식을 본뜬 가짜 데이터로 테스트합니다(`python3 -m unittest discover -s tests`). **실제 기기에 연결해 돌려 보지는 못했습니다.** 제조사·안드로이드 버전에 따라 일부 항목이 "확인하지 못한 항목"으로 나올 수 있고, 그 경우 보고서 맨 아래에 직접 확인할 방법이 표시됩니다.

## 주의

`report.html`과 `report.json`에는 내 폰에 깔린 앱 목록이 그대로 들어 있습니다. 공개된 곳에 올리지 마세요. (이 폴더의 `.gitignore`가 보고서 폴더를 깃에서 제외합니다.)
